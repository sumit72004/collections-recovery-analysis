# Collections Recovery Audit

## Objective

Investigate whether the reported 11% month-on-month recovery improvement
represents genuine collection performance improvement, identify data-quality
and attribution issues, and recommend where ₹10 Cr should be invested.

## Key finding

The reported 11% improvement is not evidence of an 11% improvement in
collection effectiveness.

Feb → Mar clean recovery increased by 11.03%, but recovery per payer
fell by 0.26% and PTP kept performance also deteriorated.

## Recommendation

Invest in Better Borrower Targeting, subject to a controlled experiment.

Planning case:
- Investment: ₹10 Cr
- Break-even lift: ~4.60%
- 5% lift scenario: ~₹10.87 Cr incremental recovery
- Gross benefit/cost: ~1.09x
- Net ROI: ~8.7%
